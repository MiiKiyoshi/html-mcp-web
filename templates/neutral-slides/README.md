# Neutral slides skin

The engine's default look: dark title bar, muted accent, no organization marks. Content
format, page kinds, and the component vocabulary are documented once in
[`../README.md`](../README.md); this skin overrides nothing, so `skin.css` is empty and
there is no `skin.json`.

[`content.html`](content.html) is a copy-ready starting document showing every page
kind and component.
