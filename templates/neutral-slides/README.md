# Neutral slides skin

The engine's default look: dark title bar, muted accent, no organization marks. The
content format is in [`../README.md`](../README.md), and the page kinds and components in
[`../KITS.md`](../KITS.md). This skin overrides nothing, so `skin.css` is empty and there
is no `skin.json`.

[`content.html`](content.html) is a copy-ready starting document showing every page
kind and component.
